# Git Pulse REST API Reference

This document describes the public and internal REST API endpoints exposed by **Git Pulse Server**.

- **Production Endpoint**: `https://git-pulse-server.vercel.app/api/v1`
- **Interactive Swagger Documentation**: `https://git-pulse-server.vercel.app/api/docs`
- **Default Local Port**: `http://localhost:6101/api/v1`

---

## 1. Health & Telemetry

### `GET /health`

Returns live service status, version, and database connectivity.

**Response (200 OK)**:

```json
{
  "status": "ok",
  "service": "git-pulse-server",
  "database": "connected",
  "version": "0.3.1",
  "timestamp": "2026-11-17T17:07:06.606Z"
}
```

## 2. Authentication & IAM (Central Gateway SSO)

### `GET /auth/me`

Retrieves authenticated user session information.

**Headers**:

- `Cookie: git_pulse_session=<JWT>`

**Response (200 OK)**:

```json
{
  "user": {
    "id": "uuid-v4",
    "username": "developer",
    "email": "dev@example.com",
    "avatarUrl": "https://avatars.githubusercontent.com/u/123",
    "role": "USER",
    "isActive": true
  }
}
```

### `POST /auth/login`

Authenticates user with username & password or development bypass.

### `POST /auth/register`

Creates a local shadow profile and issues a session cookie.

### `POST /auth/google`

Forwards Google credential or token to Central Gateway via authenticated S2S call, syncing local user profile.

### `POST /auth/sso/callback`

Exchanges OAuth2 authorization code with PKCE verification against Central Gateway IAM.

### `POST /auth/logout`

Clears session cookies and terminates the active session.

## 3. GitHub Workspace & Token Vault

### `GET /github/status`

Returns connection status, username, linked avatar, and granted scopes.

**Response (200 OK)**:

```json
{
  "isConnected": true,
  "gitUsername": "octocat",
  "gitAvatar": "https://avatars.githubusercontent.com/u/583231",
  "authType": "PAT",
  "tokenStatus": "ACTIVE",
  "hasExcessiveScopes": false,
  "scopes": ["repo", "read:user"],
  "expiresAt": "2026-12-31T23:59:59.000Z"
}
```

### `POST /github/pat`

Validates Personal Access Token with GitHub API, verifies scopes, derives user-specific key with HKDF, encrypts with AES-256-GCM, and stores in PostgreSQL.

**Rate Limit**: `@Throttle` 5 requests/min.

**Request Body**:

```json
{
  "token": "github_pat_..."
}
```

### `DELETE /github/disconnect`

Irrevocably removes GitHub account association and purges encrypted token from database with audit logging.

### `GET /github/activity`

Fetches pull requests, issues, and commit history across developer's contributed repositories within a given timeframe.

**Query Parameters**:

- `since` (optional, ISO 8601): Beginning of activity window.

## 4. Dual-Core AI Engines

### `POST /ai/summarize`

Synthesizes daily standup bullets using the GitHub Models API directly with the user's decrypted GitHub token.

**Request Body**:

```json
{
  "prs": [
    {
      "repo": "owner/repo",
      "title": "feat: integrate vercel serverless",
      "commits": ["chore: update docs", "feat: express adapter"]
    }
  ],
  "model": "gpt-4o-mini",
  "tone": "STANDUP_BULLETS",
  "language": "vi",
  "customPrompt": ""
}
```

**Response (200 OK)**:

```json
{
  "bullets": [
    "Hoàn tất tích hợp Vercel Serverless Function entry point.",
    "Tối ưu hóa pipeline CI/CD và xác thực tự động trên GitHub Actions."
  ],
  "rawText": "...",
  "modelUsed": "gpt-4o-mini",
  "engine": "GITHUB_MODELS"
}
```

### `POST /ai/save-client-summary`

Persists standup report generated locally in the browser by WebLLM (WebGPU).

## 5. Report History & Bookmarks

### `GET /reports`

Lists historical standup reports generated by the user.

### `DELETE /reports/:id`

Deletes a specific standup report by ID.

## 6. Service-to-Service (S2S) Protocol

Inbound S2S requests from Central Gateway or Wonderlab require:

| Header            | Description                       | Example                  |
| :---------------- | :-------------------------------- | :----------------------- |
| `X-S2S-Service`   | Identity slug of sending service  | `central-gateway`        |
| `X-S2S-Timestamp` | Epoch timestamp in ms             | `1794934500000`          |
| `X-S2S-Signature` | HMAC-SHA256 hex digest of payload | `a3b8...`                |
| `Authorization`   | Optional fallback Bearer token    | `Bearer <shared_secret>` |
